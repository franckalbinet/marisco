MARIS Legacy

  • Show All Code
  • Hide All Code

This handler reads the MARIS master database dump, a tab-separated text file that holds every legacy dataset, and writes one MARIS NetCDF4 file for each reference (ref_id). The dump already uses MARIS lookup-table ids, so this handler needs no nomenclature reconciliation, unlike provider handlers such as helcom or geotraces. Its pipeline renames columns, fixes types and encodes:

  • Rename the dump’s columns to MARIS standard names.
  • Cast STATION to a string.
  • Drop columns that are empty or hold only the ‘Not available’ id 0.
  • Map detection-limit symbols, such as <, to MARIS ids.
  • Parse dates and encode them as seconds since 1970-01-01.
  • Fix decimal commas in coordinates and drop out-of-range values.
  • Cast the sample ids to the types the NetCDF template needs.

encode then adds global attributes, such as the bounding box, time range and Zotero citation, and writes each reference to its own file.

Column renaming

The dump uses its own column names, such as area_id, activity and station. cois_renaming_rules maps them to MARIS standard names, and RenameColumnsCB keeps only the renamed columns. The mapping is maintained by hand, because the dump schema and the NetCDF schema are independent. NC_CSV in nbs/api/configs.ipynb lists the MARIS names.

STATION as string type

The STATION column in the MARIS dump can hold mixed or numeric types, but the NetCDF template declares station as a variable-length string. CastStationToStringCB casts it to the string dtype and fills missing values with an empty string:

source

CastStationToStringCB

def CastStationToStringCB(
    grps:list=None, # Groups to process; None = all groups in `tfm.dfs`
):

Convert STATION column to string type, filling any missing values with empty string

dfs_mock = {'SEAWATER': pd.DataFrame({'STATION': ['A1', None, 42]}), 'BIOTA': pd.DataFrame({'STATION': ['B2', None]})}
tfm = Transformer(dfs_mock, cbs=[CastStationToStringCB()])
tfm()

test_eq(tfm.dfs['SEAWATER']['STATION'].dtype.name, 'string')
test_eq(tfm.dfs['SEAWATER']['STATION'].isna().sum(), 0)
test_eq(tfm.dfs['SEAWATER']['STATION'].to_list(), ['A1', '', '42'])
test_eq(tfm.dfs['BIOTA']['STATION'].to_list(), ['B2', ''])
tfm = Transformer(dfs, cbs=[  # chkstyle: ignore-node
    RenameColumnsCB(cois_renaming_rules),
    CastStationToStringCB()
])

dfs_tfm = tfm()
print(dfs_tfm['SEAWATER']['STATION'].dtype)
string

Drop all-empty columns

Some columns in the MARIS dump are entirely empty or contain only ‘Not available’ markers (id=0 in MARIS lookup tables). DropNAColumnsCB removes these columns from every group before further processing. It keeps the columns in keep, by default SMP_ID_PROVIDER. When a dataset has no provider sample ids, CastSampleIDCB fills that column with empty strings:

source

DropNAColumnsCB

def DropNAColumnsCB(
    na_value:int=0, # MARIS NA id to drop
    keep:tuple=('SMP_ID_PROVIDER',), # Columns to keep even when empty
):

Drop columns containing only NaN or ‘Not available’ (id=0 in MARIS lookup tables), except those in keep

df = pd.DataFrame(dict(STATION=['A1', 'B2'], SMP_ID_PROVIDER=[np.nan]*2, EMPTY=[np.nan]*2, MARIS_NA=[0, 0], VALUE=[1.0, 2.0]))
tfm = Transformer({'SEAWATER': df}, cbs=[DropNAColumnsCB()])
tfm()

test_eq(list(tfm.dfs['SEAWATER'].columns), ['STATION', 'SMP_ID_PROVIDER', 'VALUE'])
tfm = Transformer(dfs, cbs=[  # chkstyle: ignore-node
    RenameColumnsCB(cois_renaming_rules),
    CastStationToStringCB(),
    DropNAColumnsCB()
])

dfs_tfm = tfm()
print('Columns:', list(dfs_tfm['SEAWATER'].columns))
Columns: ['SMP_ID', 'SMP_ID_PROVIDER', 'LAT', 'LON', 'TIME', 'SMP_DEPTH', 'STATION', 'UNC', 'UNIT', 'DL', 'AREA', 'VALUE', 'NUCLIDE']

Remap detection limit values

The detection column holds detection-limit symbols as strings, such as <, = and ND. The MARIS NetCDF format stores them as integer ids from the dbo_detectlimit lookup table. RemapCB maps each symbol to its id with the table from get_lut. A value that isn’t in the table becomes 0 (Not Available).

NoteFEEDBACK TO MARIS DATA TEAM

Future MARIS dump exports should provide the detection lut integer id directly rather than its symbolic representation, removing the need for this remapping step.

Parse and encode time

MARIS NetCDF files store time as an integer number of seconds since 1970-01-01 00:00:00.0, as nbs/files/cdl/maris.cdl defines. ParseTimeCB parses the date strings in TIME, and EncodeTimeCB converts them to seconds. A missing date is dropped:

tfm = Transformer({'SEAWATER': pd.DataFrame({'TIME': ['1990-01-01', None]})}, cbs=[ParseTimeCB(), EncodeTimeCB()])
tfm()

test_eq(list(tfm.dfs['SEAWATER']['TIME']), [631152000])

Sanitize coordinates

Raw coordinates in the MARIS dump may use commas as decimal separators instead of periods, or fall outside valid lat/lon ranges. SanitizeLonLatCB converts , to . and drops rows with out-of-range values.

df = pd.DataFrame(dict(LAT=[57.25, 91.0, '57,250'], LON=[12.08, 181.0, '12,083']))
tfm = Transformer({'SEAWATER': df}, cbs=[SanitizeLonLatCB()])
tfm()

test_eq(list(tfm.dfs['SEAWATER']['LAT']), [57.25, 57.25])
test_eq(list(tfm.dfs['SEAWATER']['LON']), [12.08, 12.083])

Add sample ids

The dump provides sample_id, an internal MARIS sequential id, and samplabcode, the provider’s original sample identifier. The renaming step maps them to SMP_ID and SMP_ID_PROVIDER. CastSampleIDCB then casts SMP_ID to an integer and SMP_ID_PROVIDER to a variable-length string, and fills missing provider ids with an empty string:

source

CastSampleIDCB

    grps:list=None, # Groups to process; None = all groups in `tfm.dfs`

Cast SMP_ID to int and SMP_ID_PROVIDER to string (renamed from samplabcode in the pipeline)

df = pd.DataFrame(dict(SMP_ID=[1, 2], SMP_ID_PROVIDER=[None, 'RC1']))
tfm = Transformer({'SEAWATER': df}, cbs=[CastSampleIDCB()])
tfm()

test_eq(tfm.dfs['SEAWATER']['SMP_ID_PROVIDER'].to_list(), ['', 'RC1'])

    RenameColumnsCB(cois_renaming_rules),
    CastStationToStringCB(),
    DropNAColumnsCB(),

Encode to NetCDF

get_cbs returns the pipeline’s callbacks, in order. encode and the examples below use it, so the pipeline is defined once.

source

get_cbs

def get_cbs()->list:

Callbacks, in pipeline order, that turn MARIS dump data into MARIS-standard DataFrames

Exported source 
def get_cbs() -> list:
    "Callbacks, in pipeline order, that turn MARIS dump data into MARIS-standard DataFrames"
    return [  # chkstyle: ignore-node
        RenameColumnsCB(cois_renaming_rules),
        CastStationToStringCB(),
        DropNAColumnsCB(),
        RemapCB(lut=lut_dl, col_src='DL', col_remap='DL', default_val=0),

        EncodeTimeCB(),
        SanitizeLonLatCB(),

Encoding

encode runs the pipeline on each reference in the dump, or on the references in ref_ids, and writes each one to dest as <ref_id>.nc. marisco-ingest maris_legacy calls it.

source

encode

def encode(
    dest:str, # Path to the folder where the NetCDF output will be saved
    src:str=None, # Path to the MARIS dump data in CSV format
    **kwargs
):

MARIS legacy database dump

Exported source 
def encode(
    dest: str, # Path to the folder where the NetCDF output will be saved
    src: str = None, # Path to the MARIS dump data in CSV format
    **kwargs # Additional keyword arguments
):
    "MARIS legacy database dump"
    assert src, "maris_legacy requires `src`, the path to the MARIS dump CSV"
    dataloader = DataLoader(src)
    ref_ids = parse_ref_ids(kwargs.get('ref_ids'), valid=dataloader.df.ref_id.unique())
    print('Encoding ...')
    for i, ref_id in enumerate(ref_ids):
        dfs = dataloader(ref_id=ref_id)
        print(f'{i+1}/{len(ref_ids)}: ref_id={ref_id} -> {dest}/{get_fname(dfs)}')
        tfm = Transformer(dfs, cbs=get_cbs())
        tfm()
        encoder = NetCDFEncoder(tfm.dfs, dest_fname=Path(dest)/get_fname(dfs),
            global_attrs=get_attrs(tfm, zotero_key=get_zotero_key(dfs)), verbose=kwargs.get('verbose', False))
        encoder.encode()
